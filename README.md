# U&are

## Описание проекта
U&are - проект мессенджера, разработанный с целью создания удобной платформы для обмена сообщениями в реальном времени между пользователями.

## Проблема
Существующие мессенджеры часто перегружены функциями, имеют сложный интерфейс, заблокированы в нашей стране или требуют регистрации через социальные сети. Проект U&are направлен на создание простого и понятного инструмента для общения, где фокус сделан на удобстве использования и быстроте обмена сообщениями.
